# Van Phong Pham Website

Dự án website cửa hàng **văn phòng phẩm**, đang trong giai đoạn *sắp xếp và chuẩn hoá* dữ liệu.

| Thư mục | Nội dung |
| --- | --- |
| docs | Tài liệu nhập hàng |
| media | Logo và hình ảnh |
| data | File Excel đơn bán |
| logs | File log và báo cáo |
| backup | Bản sao lưu |

```powershell
Get-ChildItem -Recurse -Force
```
